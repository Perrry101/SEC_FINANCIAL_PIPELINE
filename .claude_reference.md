## What Was Built

A production-grade Python data pipeline that extracts balance sheet, income statement, and cash flow data from SEC EDGAR XBRL filings for ~424 U.S. manufacturing companies (1998–2026).

## Final Run Order

```bash
cd D:/SEC_FINANCIAL_PIPELINE

# Only needed once:
python cleanup_companies.py     # Deduplicate companies.csv (warrants, foreign OTC, etc.)

# Each run:
python download_filings.py      # Download SEC JSONs (~2-3 min, skips existing)
python create_dataset.py         # Build raw panel 61 cols (~6-7 min)
python data_cleaning.py          # Clean + engineer features → 71 cols (~2 sec)
```

## Architectural Decisions

- **Safe division**: `np.divide(where=...)` instead of `replace(0, NA)` — preserves rows with zero denominators
- **Forward-fill**: Only applied to balance sheet fields (stock variables), not income statement (flow variables)
- **Winsorization**: 1st/99th percentile, applied twice — once on raw columns, once on engineered growth rates
- **Metadata merge**: CIK-based left join with `companies.csv` for SIC codes and sector labels
- **Form types**: 10-Q, 10-K, 10-K/A, 10-Q/A, 20-F, 20-F/A, 40-F accepted — broader than default
